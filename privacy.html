개인정보처리방침

시행일: 2026년 9월 10일

shorts-factory(이하 "이 도구")는 운영자 본인의 PC에서 실행되는 개인용 영상 제작 도구입니다. 이 문서는 이 도구가 어떤 정보에 접근하고 어떻게 다루는지 설명합니다.

1. 접근하는 정보

이 도구는 Google 계정 로그인 시 YouTube 동영상 업로드 권한 (youtube.upload) 하나만 요청합니다. 이 권한으로는 영상을 올리는 것만 가능하며, 채널 정보·기존 영상·댓글·구독자·시청 기록 등은 읽지 않습니다. 이름, 이메일 주소, 프로필 정보도 요청하지 않습니다.

2. 정보가 저장되는 곳

로그인 후 발급되는 인증 토큰은 운영자 PC에만 파일로 저장됩니다. 이 도구에는 별도의 서버가 없으며, 토큰이나 영상을 운영자 외의 누구에게도 전송하거나 보관하지 않습니다.

3. 외부로 전송되는 정보

  • YouTube(Google) — 업로드할 영상 파일과, 운영자가 정한 제목·설명·태그가 YouTube API를 통해 YouTube로 직접 전송됩니다.
  • 음성 합성(Microsoft) — 나레이션을 만들기 위해 대본 문장이 Microsoft의 온라인 음성 합성 서비스로 전송됩니다. 대본에 개인정보를 넣지 않는 것을 권장합니다.

그 밖의 분석 도구, 광고, 쿠키는 사용하지 않습니다.

4. YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 이 도구를 사용하는 것은 아래 문서에 동의하는 것을 의미합니다.

  • YouTube 서비스 약관
  • Google 개인정보처리방침

5. 권한 해제와 삭제

언제든지 아래 방법으로 이 도구의 접근 권한을 없앨 수 있습니다.

  • Google 계정 → 타사 앱 및 서비스에서 shorts-factory의 액세스 권한을 삭제
  • 또는 Google 보안 설정의 권한 페이지에서 해제
  • PC에 저장된 토큰 파일(secrets/token.json)을 삭제

이미 업로드된 영상은 YouTube 스튜디오에서 직접 삭제할 수 있습니다.
